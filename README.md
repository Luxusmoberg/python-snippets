# Python Snippets & Dev Notes

A running collection of small, useful Python helpers plus a daily dev log.
Updated most days.

## Layout

- `snippets/` — one file per helper, each self-contained and valid Python
- `log.md` — chronological notes on what changed and why
- `grind.py` — the script that appends entries and commits

## Why

Not every day produces something worth a repo. This is the low-friction
bucket: a helper gets tightened, a note gets written, the log grows.
